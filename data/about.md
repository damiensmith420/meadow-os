## About This Site

Meadow OS is a static site hosted on GitHub Pages, styled to look like a classic early-2000s desktop operating system. It was built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step.

The release data is kept fresh by a GitHub Actions workflow that runs every 6 hours and writes a `releases.json` cache file.
